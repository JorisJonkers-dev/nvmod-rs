# Sort mode: full or minimal (#84)

- **Question:** how does a caller ask for the loot-rs minimal-change sort?
- **Decision:** `nvmod sort --mode full|minimal` and `nvmod_api::loadorder::SortRequest::mode` (`SortMode`, default `Full`) pass the mode to loot-rs. `--json` names the mode (`mode`) and already counts the positions changed (`positions.changed`). The default stays the full sort; an imported Instance keeps its order until a person asks for a sort (`--keep-order` is unchanged), and `--mode` is refused with `--keep-order`.
- **Why:** loot-rs 0.8.1 has the mode (loot-rs #47); the Toolbox can pass it through the library call. Changing what an imported Instance gets by default would reshuffle Load orders without being asked.
- **Revisit:** no.
